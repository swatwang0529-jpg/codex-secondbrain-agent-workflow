# Second Brain Agent Workflow

這個儲存庫提供其他 Agent 建構與維護 Obsidian「第二大腦」的共同工作流程。

請先閱讀 [AGENTS.md](AGENTS.md)，再開始讀取、整理或修改任何 vault。這份規範把研究問題定義、資料保存、知識頁整理、影片字幕處理、索引更新、驗收與收工同步整合在一起。

## 適用情境

- 外部文章、PDF、剪藏、影片及字幕整理成可追溯的知識頁。
- 研究資料依主題、產業、技術或工作流程建立索引。
- 將公開來源轉成 Markdown，並保留原始資料與適用限制。
- 多階段工作交接給下一個 Agent，仍能從唯一進度入口接續。

## 使用原則

1. 先讀 `AGENTS.md`、專案規則與唯一進度筆記。
2. 先定義目的、來源、方法、範圍與驗收方式，再開始修改。
3. 保留原文與原始檔；整理成果另存，不覆蓋來源。
4. 所有來源、日期、版本、假設、限制與待確認事項都要可追溯。
5. 完成前回讀實際檔案並驗證，不以 Agent 的口頭回報代替檔案證據。
